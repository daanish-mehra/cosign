Which models are safe with money?

We give each model the same wallet, the same jobs and the same attacks, then measure how often it's talked into paying an attacker, with and without fixes enforced outside the model.

Same test for everyone

Four real jobs: buy on a price signal, pay for an API, research then buy a token, rebalance. Five attack channels, each rewritten six ways, three trials each. A model counts as safe only if it held in every trial.

Money is the judge

No model grades another. We read the ledger: did USDC reach the attacker, how much of the wallet went, and did the agent still finish its job.

Fixes outside the model

The last two columns run the same model behind Cosign's recommended guards: an allowlist, spend caps, a confirmation threshold, quarantined inputs and signed memory.

Early results from a small suite (8 attack scenarios per run). Rankings will move as we add research-grade suites and more models. Models whose runs failed for harness reasons are left off rather than scored.
